ONE 8 — Sports & Fashion
========================
Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome, Edge, Firefox, etc.
3. No build step or server is required.

Features:
- Responsive sports + fashion landing page
- Animated hero graphic
- Interactive cursor
- Scroll reveal animations
- Product 3D hover effect
- Mobile navigation
- Newsletter interaction
- Google Fonts
